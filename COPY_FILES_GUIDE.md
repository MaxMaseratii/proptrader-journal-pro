# How to Copy Files from This Project

## Step 1: Select All Files in This Project

**In the left sidebar (file explorer):**
1. Click anywhere in the file list
2. Press **Ctrl+A** (Windows) or **Cmd+A** (Mac) to select everything
3. You'll see all files highlighted

**What you should see selected:**
- All folders: `client/`, `server/`, `shared/`
- All files: `package.json`, `vite.config.ts`, etc.

## Step 2: Copy Everything

After selecting all files:
- Press **Ctrl+C** (Windows) or **Cmd+C** (Mac)

## Step 3: Go to Your New Project

1. Click the "Create New Copy" button on your dashboard
2. This opens a new Replit project
3. Delete any default files in the new project

## Step 4: Paste Everything

**In your new project:**
1. Click in the file explorer area
2. Press **Ctrl+V** (Windows) or **Cmd+V** (Mac)
3. All files will be copied over

## Alternative: Manual File Copy

If Ctrl+A doesn't work:

**Copy each main folder:**
1. Right-click on `client/` folder → Copy
2. Go to new project → Right-click → Paste
3. Repeat for `server/` folder
4. Repeat for `shared/` folder
5. Copy individual files like `package.json`, `vite.config.ts`, etc.

## Where to Find Files

**Left Sidebar = File Explorer**
- This shows all your project files
- Folders have arrow icons you can click to expand
- Files show with their extensions (.tsx, .ts, .json, etc.)

## Quick Test

After copying, your new project should have:
- `client/` folder with all React components
- `server/` folder with API code
- `shared/` folder with database schema
- Root files like `package.json`

The file structure should look identical to this current project.
