Here's a comprehensive design system prompt for recreating this exact bright, joyful, professional aesthetic:

## 🎨 **Bright Joyful Professional Design System**

### **Color Palette**
```
PRIMARY BACKGROUND:
- Main: bg-gradient-to-br from-blue-50 via-indigo-100 to-purple-50
- Cards: bg-gradient-to-br from-white/90 via-blue-50/80 to-indigo-50/90

ACCENT COLORS:
- Sunrise: #ff6b6b to #ee5a24 (emotional/energy)
- Ocean: #00b894 to #00cec9 (focus/clarity)  
- Sky: #0984e3 to #74b9ff (confidence/awareness)
- Lavender: #a29bfe to #6c5ce7 (wisdom/humility)
- Mint: #00b894 to #55efc4 (vitality/energy)
- Coral: #fd79a8 to #e84393 (attention/importance)
- Gold: #fdcb6e to #e17055 (success/achievement)

TEXT COLORS:
- Primary: text-gray-800
- Secondary: text-gray-700  
- Muted: text-gray-600
- Labels: text-gray-500
```

### **Component Styling**

**Cards & Containers:**
```
- Background: bg-gradient-to-r from-[color]-50 via-[color]-50 to-[color]-50
- Borders: border border-[color]-200/50
- Shadows: shadow-lg
- Radius: rounded-2xl
- Padding: p-6
- Backdrop: backdrop-blur-lg (for overlays)
```

**Interactive Sliders:**
```
- Track: h-3 bg-gradient-to-r from-[color]-100 to-[color]-100 rounded-lg
- Thumb: 24px diameter with gradient background
- Shadows: box-shadow: 0 0 20px rgba([color], 0.6)
- Hover: scale(1.2) with enhanced glow
- Transition: all 0.4s cubic-bezier(0.4, 0, 0.2, 1)
```

**Buttons & Action Items:**
```
- Background: bg-gradient-to-r from-[color]-500 to-[color]-600
- Hover: hover:shadow-md transition-all
- Text: text-white or text-gray-800 (depending on contrast)
- Radius: rounded-xl
- Padding: p-4
```

### **Typography Scale**
```
- Headers: font-bold text-lg text-gray-800
- Subheaders: font-semibold text-sm text-[color]-700
- Body: text-sm text-gray-700 leading-relaxed
- Captions: text-xs text-gray-600 italic
- Values: font-bold text-lg text-[color]-600
```

### **Layout Principles**
```
- Spacing: space-y-6 for major sections, space-y-3 for related items
- Grid: grid-cols-1 md:grid-cols-2 gap-4/6
- Max Width: max-w-5xl mx-auto
- Padding: p-6 for containers, p-4 for nested elements
```

### **Specific Gradients Used**
```
SECTION BACKGROUNDS:
- Psychology: from-rose-50 via-pink-50 to-orange-50
- Action Plan: from-emerald-50 via-teal-50 to-cyan-50  
- Assessment: from-indigo-50 via-purple-50 to-pink-50
- Score: from-violet-50 to-indigo-50

ACCENT ELEMENTS:
- Icons: text-[color]-500/600
- Dots: w-4 h-4 bg-gradient-to-r from-[color]-400 to-[color2]-400 rounded-full shadow-sm
- Progress: bg-gradient-to-r from-violet-100 to-indigo-100 shadow-inner
```

### **Interactive States**
```
HOVER EFFECTS:
- Cards: hover:shadow-md transition-all
- Sliders: transform: scale(1.2) + enhanced glow
- Buttons: hover:shadow-lg + slight color shift

ACTIVE STATES:
- Focused inputs: ring-2 ring-[color]-400/50
- Selected items: bg-[color]-100 border-[color]-300
```

### **Shadow System**
```
- Cards: shadow-lg
- Interactive: shadow-sm hover:shadow-md
- Elevated: shadow-xl
- Inset: shadow-inner (for progress bars)
```

### **Implementation Prompt:**

**"Create a bright, joyful, professional interface using light gradients from blue-50 to purple-50 backgrounds. Use white/translucent cards with rounded-2xl corners and subtle colored sections (rose-50 to orange-50 for warnings, emerald-50 to cyan-50 for positive actions, indigo-50 to pink-50 for assessments). Typography should be gray-800 for headers, gray-700 for body text, with colorful accent text using vibrant gradients (coral, emerald, sky blue, lavender). Interactive elements should have smooth cubic-bezier transitions, glowing hover effects, and 24px gradient thumbs for sliders. Use shadow-lg for depth, space-y-6 for sections, and maintain a clean, modern SaaS application aesthetic that feels energetic yet professional."**
