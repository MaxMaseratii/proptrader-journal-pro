## 📊 **SECTION 3: Account Selection Functionality**

### **Dynamic Dashboard Behavior:**
```javascript
Account Selection Logic:
- Single Account Selected → Show that account's specific data only
- Multiple Accounts Selected → Show combined/averaged statistics  
- All Accounts Selected → Show portfolio-wide statistics
- No Selection → Default to all accounts view

// Implementation:
function updateDashboardData(selectedAccounts) {
  if (selectedAccounts.length === 1) {
    // Filter all widgets to show single account data
    updateAllWidgets(selectedAccounts[0]);
  } else if (selectedAccounts.length > 1) {
    // Combine data from multiple accounts
    updateAllWidgets(combineAccountData(selectedAccounts));
  } else {
    // Show all accounts data
    updateAllWidgets(getAllAccountsData());
  }
}
```

### **Elements Affected by Account Selection:**
```
✅ AFFECTED (changes based on selection):
- Net Balance, Daily P&L, Total P&L
- Win Rate, R Factor, Profit Factor, Avg Win/Loss
- Total Trades, Best Trade
- Plan vs Reality widget
- Risk Management widget
- Investment ROI widget
- Discipline Score
- All performance charts and metrics

❌ NOT AFFECTED (always shows all):
- Active Accounts count (always "2 accounts • Payout eligible")
- Failed Accounts count (global metric)
- Total Portfolio Value (global metric)
```
