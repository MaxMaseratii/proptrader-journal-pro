## 🎯 **CHANGE LOCATION 4: ADD ACCOUNT SELECTION FUNCTIONALITY**

### **📍 WHERE TO ADD FUNCTIONALITY:**
- **Location**: Dashboard JavaScript/Logic layer
- **Affects**: All dashboard widgets (except specified exceptions)

### **🔧 ADD THIS LOGIC:**
```javascript
// Add to dashboard data management
function updateDashboardData(selectedAccounts) {
  if (selectedAccounts.length === 1) {
    // Single account selected - show only that account's data
    updateAllWidgets(selectedAccounts[0]);
    updateSelectionStatus("Analyzing 1 selected account");
  } else if (selectedAccounts.length > 1) {
    // Multiple accounts selected - show combined data
    updateAllWidgets(combineAccountData(selectedAccounts));
    updateSelectionStatus(`Showing combined stats for ${selectedAccounts.length} accounts`);
  } else {
    // No selection or all accounts - show portfolio-wide data
    updateAllWidgets(getAllAccountsData());
    updateSelectionStatus("Showing all accounts");
  }
  
  // EXCEPTION: Keep these widgets always showing all accounts
  keepUnchanged(['active-accounts-count', 'failed-accounts-count', 'total-portfolio-value']);
}
```

### **🎯 WIDGETS AFFECTED BY ACCOUNT SELECTION:**
```
✅ CHANGES WITH SELECTION:
- Net Balance, Daily P&L, Total P&L
- Win Rate, R Factor, Profit Factor, Avg Win/Loss
- Total Trades, Best Trade
- Plan vs Reality widget
- Risk Management widget
- Investment ROI widget
- Discipline Score widget
- Weekly Navigation data
- All performance charts and metrics

❌ ALWAYS SHOWS ALL ACCOUNTS:
- Active Accounts count (always "2 accounts • Payout eligible")
- Failed Accounts count 
- Total Portfolio Value
```
