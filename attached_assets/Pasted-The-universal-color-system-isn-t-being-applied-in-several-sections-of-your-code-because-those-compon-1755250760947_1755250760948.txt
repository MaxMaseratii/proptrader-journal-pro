How to Fix It
To make your color system truly universal, you need to replace all hardcoded color classes and divergent color functions with your getValueColor function.

Step 1: Identify Hardcoded Colors
Search your file for static color classes applied to dynamic data, such as:

text-green-500

text-red-500

text-blue-400

text-amber-400

text-cyan-400

Step 2: Replace with getValueColor
Replace the static classes with a call to your getValueColor function, passing in the relevant numerical value and, importantly, the correct context.

Example: Fixing the "Profit Factor" widget in "Performance Overview"

JavaScript

// BEFORE (Incorrect ❌)
<div className="text-2xl font-bold mb-1 text-green-500">
  {combinedAnalytics?.profitFactor?.toFixed(2) || '0.00'}
</div>

// AFTER (Correct ✅)
<div className={`text-2xl font-bold mb-1 ${getValueColor(combinedAnalytics?.profitFactor, 'roi')}`}>
  {combinedAnalytics?.profitFactor?.toFixed(2) || '0.00'}
</div>
In this case, a profit factor greater than 1 is good (green) and less than 1 is bad (red). You might need to adjust the value passed, for example: getValueColor(combinedAnalytics?.profitFactor - 1, 'roi').

Step 3: Unify All Color Functions
Replace calls to other color functions like getPercentageColor with your universal one to ensure a single source of truth.

Example: Fixing the "Win Rate" widget

JavaScript

// BEFORE (Incorrect ❌)
<div className={`text-2xl font-bold mb-1 ${getPercentageColor(combinedAnalytics?.winRate || 0).textColor}`}>
    {formatPercentage(combinedAnalytics?.winRate || 0)}
</div>

// AFTER (Correct ✅)
<div className={`text-2xl font-bold mb-1 ${getValueColor(combinedAnalytics?.winRate, 'roi')}`}>
    {formatPercentage(combinedAnalytics?.winRate || 0)}
</div>
(You may need to ensure your getUniversalValueColor function has a context that properly handles percentages, like 'roi' or a new 'percentage' context).
